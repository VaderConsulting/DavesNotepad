# DavesNotepad

VB.NET MDI notepad that opens .txt files into child frmFile windows with a docked multiline editor. ParentForm implements New Window (numbered MDI children), Open via StreamReader, cascade/tile, and toolbar/status visibility; Save As and clipboard commands are still TODO stubs. Class1 is a naming-style scratch class and is not wired into the UI.
